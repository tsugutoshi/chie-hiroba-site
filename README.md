# ちえのひろば

3〜6歳のお子さま向け知育アプリ「ちえのひろば」の紹介サイトです。

## Webサイト

- 紹介サイト：https://tsugutoshi.github.io/chie-hiroba-site/
- プライバシーポリシー：https://tsugutoshi.github.io/chie-hiroba-site/privacy.html
- 利用規約：https://tsugutoshi.github.io/chie-hiroba-site/terms.html

アプリは一般公開に向けて準備中です。サイトには紹介用のアプリ画面を掲載しており、ブラウザー上でゲームを実行するものではありません。

## 構成・更新

静的HTML/CSS/JavaScriptを `docs/` に配置しています。GitHub Pagesは `main` ブランチの `/docs` を配信します。ビルドや外部パッケージのインストールは不要です。変更をmainへpushすると自動でサイトが更新されます。

外部フォント配信、アクセス解析、Cookie、問い合わせフォームのサーバー処理は使用していません。お問い合わせリンクはメールアプリを開きます。
